# ShopNest Store Performance Analysis – Power BI

## Project Overview

This project focuses on analyzing ShopNest Store performance using Microsoft Power BI.

The analysis was performed using multiple datasets covering orders, order items, products, customer reviews, payments, and related information.

## Dataset

The project included multiple datasets containing information about:

- Orders
- Order Items
- Products
- Customer Reviews
- Payments
- Customers and locations

The project included:

- 99K+ orders
- 112K+ order items
- 32K+ products
- 100K reviews

## Analysis Performed

The Power BI report was used to analyze:

- Product category sales
- Delayed orders
- Seasonal trends
- Payment methods
- State-wise sales
- Revenue
- Customer ratings

## Key Insights

Some of the findings from the analysis included:

- Health & Beauty accounted for 9.38% of item sales.
- Credit cards accounted for 78.34% of payment value.
- 8.11% of delivered orders were delayed.
